# Nexwall Vue components

Vue 3 component library used by the Nexwall Firewall web interface (buttons, forms, tables, drawers, tabs and
layout helpers), styled with Tailwind CSS.

```
import { NeButton, NeTabs } from '@nexwall/vue-components'
```

The library ships its theme (`@nexwall/vue-components/theme.css`) with the Inter font and the Nexwall indigo palette.
